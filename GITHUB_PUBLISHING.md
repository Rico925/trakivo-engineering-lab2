# Publishing TRAKIVO to GitHub

## Before publishing

- Review every file for secrets, personal data, and licensed telemetry.
- Keep `.env` out of Git. Commit `.env.example` only; it contains placeholders.
- Use synthetic or data you have permission to publish. The included CSV is a demo fixture.
- Do not describe the prototype as a validated vehicle simulator, live telemetry platform, or production-ready knowledge graph.
- Do not claim Supabase/pgvector is integrated. `supabase/schema.sql` is a starter schema only.

## Suggested repository details

**Repository name:** `trakivo-engineering-lab`

**Short description:** `An educational motorsport engineering prototype for deterministic setup experiments, CSV telemetry comparison, and evidence-bound AI explanations.`

**Topics:** `motorsport`, `engineering-education`, `telemetry-analysis`, `python`, `fastapi`, `react`, `vite`, `simulation`, `groq`

**Suggested public repo layout:**

- `frontend/` React + Vite website
- `src/python/brain/` FastAPI experiment and telemetry API
- `tests/` Python API/model tests
- `src/node/`, `src/cpp/`, `src/proto/` legacy scaffolding; explicitly mark as not wired into the main UI flow
- `examples/demo_telemetry.csv` synthetic sample data
- `examples/knowledge-graph-concept.html` static mockup, not a database-backed RAG implementation
- `supabase/schema.sql` starter schema only, not wired to the app
- `README.md`, `TELEMETRY_SCHEMA.md`, `TEST_REPORT.md`

## Local commands before first push

Run from the project root:

```bash
python -m pip install -r src/python/brain/requirements.txt
python -m pytest -q
PYTHONPATH=src/python python -c "from brain.api import app; print(app.title)"
```

In a second terminal:

```bash
cd frontend
npm install
npm run build
```

Commit `frontend/package-lock.json` generated by a successful `npm install`. Do not claim a successful frontend build until `npm run build` exits with code 0.

## Git commands

Create an empty repository on GitHub first, without auto-generating a README or license if you already have these files locally. Then run from the project root:

```bash
git init
git add .
git status --short
```

Review `git status` and confirm `.env`, `.venv/`, `node_modules/`, and `frontend/dist/` are not staged. Then:

```bash
git commit -m "Prepare TRAKIVO engineering lab prototype"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/trakivo-engineering-lab.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username and the URL with the repository URL GitHub gives you. If `origin` already exists, inspect it with `git remote -v` rather than adding a second remote.

## Suggested GitHub README opening

> TRAKIVO Engineering Lab is an educational prototype exploring a repeatable engineering learning loop: define a hypothesis, record a prediction, run a deterministic simplified model, compare imported telemetry, and save a learning record. The current gearing model is illustrative and not validated for real vehicle setup or safety decisions. AI is an optional explanation layer and does not own numerical calculations.
